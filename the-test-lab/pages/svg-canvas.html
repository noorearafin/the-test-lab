Clickable SVG

Standard XPath won't match SVG elements. Use CSS selectors, or //*[name()='circle'].

#svgStage circle//*[name()='rect'][data-testid="svg-star"]
Click a shape.

SVG bar chart

Hover a bar to read its value from the tooltip. Values are also in data attributes.

.bar[data-month="Mar"]#chartTooltip

Drawing canvas

Canvas pixels aren't in the DOM. Draw with mouse actions and assert on the stroke counter or a screenshot.

#drawCanvas#strokeCount
